Notes for later code testing
----------------------------

If STELAR-Pro is implemented correctly for this case:
  - No leaf taxon should be lost from any tree.
  - D-rooted bipartitions listed above should not enter the candidate set.
  - The child speciation nodes below D roots should still be traversed and kept.
  - Hashing should treat duplicated ranges as species sets. For example, both
    children of T1.D1 have occurrence cluster [1,2], not [1,2,1,2].
  - Range intersections should count species once. For example, the intersection
    between occurrence range [1,2,1,2] and a range containing {1,2,3} is 2, not 4.
